# waen (แว่น)

แว่นแปลหน้าจอสำหรับเล่นเกม — เฝ้าดูพื้นที่บนหน้าจอ อ่านข้อความอังกฤษด้วย OCR
แล้ววาดคำแปลไทย **ลอยเหนือข้อความต้นฉบับโดยไม่บังต้นฉบับ**

- Windows 10 (2004+) / 11 · Python 3.11+
- เป้าหมายแรก: Persona 5 Royal (PC)
- แปล en → th ด้วย Google Translate ฟรี (ไม่ต้องมี API key)
