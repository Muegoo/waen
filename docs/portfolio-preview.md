# Synthetic overlay preview

The portfolio image and GIF use original example sentences, fixed translations and the real `OverlayWindow` widget. They demonstrate rendering and source/translation placement. They do not run capture, OCR, a game, or an online translation request.

From a development environment with the existing dependencies:

```powershell
python -m scripts.render_portfolio_preview
```

No commercial game screenshot is used for these preview assets. For live performance evidence, use the separately scoped OCR reports and perform the manual checks in the README.
